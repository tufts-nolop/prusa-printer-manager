This repo tracks **website functionality** only.

## Issues: what to file
Open an issue if it’s about:
- A bug/error on the site
- A specific improvement to how the site works
- A new feature request for the site

Do **not** open issues for:
- General complaints with no details
- Questions unrelated to the site’s functionality
- Non-actionable reports (“it’s broken”)

## Bug reports (keep it brief)
Include (if you can):
- What you were trying to do
- What happened (exact error message if any)
- Steps to reproduce (1–3 steps is fine)
- Where it happened (page/URL)
- Screenshot if relevant

## Feature requests (keep it brief)
Include:
- What you want added/changed
- Why it’s needed (1–2 sentences)
- What “done” looks like (a short bullet list)
